# PROJETOMIPS
Processador MIPS Monociclo em Verilog

Visão Geral do Projeto
Este projeto consiste no desenvolvimento e implementação de uma versão simplificada do núcleo de um processador **MIPS Monociclo (Single-Cycle)** em hardware utilizando a linguagem de descrição de hardware **Verilog**.

A arquitetura foi projetada de forma modular e hierárquica, onde cada componente do fluxo de dados e da unidade de controle foi implementado em arquivos separados para garantir a organização e a facilidade de manutenção do sistema.

Especificações Técnicas e Ferramentas
**Linguagem:** Verilog (HDL)
**Ambiente de Desenvolvimento/Simulação:** Quartus
**Tipo de Arquitetura:** Monociclo (Single-Cycle)
